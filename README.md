# Flourish — Starting Out

Investor materials for **Flourish** (*Every First, Forever*) — a privacy-first digital scrapbook for new parents.

## Business plan

| Format | Path |
|---|---|
| **Display (HTML)** — open in a browser or Print → Save as PDF | [`business-plan/index.html`](./business-plan/index.html) |
| **Markdown source** — editable full document | [`docs/Flourish-Investor-Business-Plan.md`](./docs/Flourish-Investor-Business-Plan.md) |

### Quick start

1. Open `business-plan/index.html` in any browser to present to investors.
2. Use **Print / Save PDF** in the page header for a shareable PDF.
3. Edit `docs/Flourish-Investor-Business-Plan.md` when you refine numbers, raise size, or traction metrics.
